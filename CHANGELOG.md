# Changelog

## [1.0.0 - 3.0.28] - 2024-08-31 to 2026-01-03

Summary of the v1–v3 history, prior to the v4 rewrite. See git history for full per-version detail.

- **v1**: Established core primitives — `ArvoEvent`, `ArvoContract`, `ArvoContractLibrary`, event factories, HTTP formats, and OpenTelemetry integration.
- **v2**: Introduced versioned contracts, simplified orchestrator contracts, and adopted Biome for linting.
- **v3**: Added event domains for orchestration segregation and human-in-the-loop workflows, `parentid` causality tracking, `ViolationError` type guarding, and OTEL logging refinements.

v4 onward is managed via [Changesets](https://github.com/changesets/changesets); new entries are generated automatically from `.changeset/` files.
